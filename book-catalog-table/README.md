# 📚 Book Catalog Table

A simple HTML project that displays a collection of books in a structured and accessible table. This project focuses on practicing semantic HTML table elements, including table headers, table bodies, table data cells, and table footers.

## 👀 Preview

The project displays a book catalog containing fictional books, their authors, genres, and publication years.

## 📖 Overview

This project was built as part of a freeCodeCamp lab focused on creating and structuring HTML tables.

The catalog includes:

* Book titles
* Authors
* Genres
* Publication years
* A total book count in the table footer

The project uses semantic table elements to organize the information clearly.

## 🧠 What I Learned

Through this project, I practiced:

* Creating HTML `<table>` elements
* Using `<thead>` for table headers
* Using `<tbody>` for table content
* Using `<tfoot>` for summary information
* Creating table rows with `<tr>`
* Creating header cells with `<th>`
* Creating data cells with `<td>`
* Using `colspan` to span multiple columns
* Structuring tabular information with semantic HTML
