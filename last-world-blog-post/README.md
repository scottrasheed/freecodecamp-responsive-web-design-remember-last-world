# Last World — The Ruins Beneath Ashfall

A dark fantasy blog post card inspired by **Last World**, featuring a volcanic ash-covered environment and the mysterious discovery of something ancient beneath the ruins.

## Preview

The project presents a cinematic blog post card depicting **Ashfall** — a ruined settlement surrounded by volcanic mountains, falling ash, embers, and an ominous glow suggesting that a powerful Relic may be hidden beneath the destruction.

The visual is intended as **Last World concept art**, rather than finalized game canon.

## About the Project

This project was created as a frontend design exercise focused on building a visually immersive card using only **HTML and CSS**.

Instead of relying on external images, the Ashfall environment is constructed entirely with CSS shapes, gradients, shadows, clipping paths, and layered effects.

The goal was to create the feeling of:

* A volcanic wasteland
* A settlement destroyed by Ashfall
* Ancient ruins disappearing beneath volcanic ash
* Falling ash and atmospheric fog
* Distant volcanic light
* A mysterious Fire Relic hidden beneath the ruins

## Design Inspiration

The visual direction is inspired by the world of **Last World**:

> After the Collapse, ancient places remain buried beneath forgotten landscapes. Ashfall is one such place — a ruined settlement surrounded by volcanic mountains where something powerful may still remain.

The Fire Relic glow is intentionally subtle. It represents the possibility of discovery without permanently defining what the Relic or Ashfall looks like in the final game.

## Last World

**Last World** is a long-term fantasy MMORPG concept centered around exploration, ancient Relics, elemental powers, forgotten civilizations, and the mysteries left behind after **The Collapse**.

This project is one of the smaller frontend experiments used to develop the visual identity and presentation style of the Last World universe.

## What I Practiced

This project helped practice:

* Structuring semantic HTML
* Building visual environments without external images
* Layering CSS elements
* Creating atmospheric lighting
* Using gradients for environmental effects
* Creating shapes with `clip-path`
* Responsive layouts
* Accessibility considerations
* Designing a reusable card component
