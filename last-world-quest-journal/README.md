# ⚔️ Last World — Quest Journal

A stylized quest journal inspired by **Last World**, built while practicing HTML and CSS through FreeCodeCamp's Responsive Web Design curriculum.

Instead of creating a traditional to-do list, this project reimagines the required structure as a fantasy MMORPG quest log.

---

## 🌎 About the Project

The goal of this project was to practice working with:

- Unordered lists
- Nested lists
- Checkboxes
- Labels
- Links
- Link states
- CSS styling
- Responsive layouts

The original exercise focuses on creating a styled to-do list and practicing different states for links.

I decided to turn the concept into something that could actually belong inside **Last World**.

The result is a quest journal where each checkbox represents a quest and each sub-item represents an objective.

## 🎮 Last World

**Last World** is an original medieval fantasy MMORPG concept centered around a world recovering from a catastrophic event known as **The Collapse**.

Powerful Relics containing primordial elemental forces were scattered throughout the world.

Players will eventually explore kingdoms, forests, islands, ruins, forgotten civilizations, and dangerous lands while discovering Relics and uncovering the truth behind The Collapse.

The long-term vision is to eventually develop Last World into a large-scale 3D MMORPG.

## 🎯 Why I Built It This Way

Rather than treating every FreeCodeCamp exercise as something completely separate from my own interests, I'm using some of the exercises as opportunities to experiment with ideas for Last World.

This project is one example.

A simple to-do list became:

> **A quest journal.**

The list became a quest chain.

The links became objectives.

And the styling became an early experiment with the visual identity of Last World.
