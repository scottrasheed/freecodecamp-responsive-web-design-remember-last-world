# 🎬 Design a Movie Review Page

A movie review webpage built with HTML, featuring *Eternal Sunshine of the Spotless Mind*, starring Jim Carrey and Kate Winslet.

## 👀 Preview

The page includes:

* Movie title
* Movie cover image
* Brief movie description
* Movie rating
* Cast member list
* Character names

## 📖 Overview

This project was created as part of a freeCodeCamp Responsive Web Design lab focused on building a structured movie review page.

For the project, I chose *Eternal Sunshine of the Spotless Mind*, a 2004 romantic science-fiction drama starring Jim Carrey as Joel Barish.

The page uses semantic HTML elements to organize the movie information and includes accessibility features for the rating and movie image.

## 🧠 What I Learned

Through this project, I practiced:

* Creating a semantic `<main>` element
* Structuring content with headings
* Adding images with descriptive `alt` text
* Creating accessible movie ratings
* Using `aria-hidden` for decorative rating stars
* Creating unordered lists with `<ul>` and `<li>`
* Using `<b>` elements for emphasized names
* Structuring information with semantic HTML

## ♿ Accessibility

The project includes accessibility-focused HTML features:

* Descriptive `alt` text for the movie image
* `aria-hidden="true"` on the visual rating stars so screen readers don't read the decorative stars individually
* Semantic headings and list elements for structured content
