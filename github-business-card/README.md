# ⚔️ Last World — Developer Business Card

A custom developer business card inspired by **Last World**, an original medieval fantasy MMORPG concept.

The project combines a professional developer portfolio card with the visual identity of Last World — dark fantasy atmosphere, ancient relics, elemental energy, and the mysterious world left behind after **The Collapse**.

This business card is designed to feel like a small piece of the Last World universe while still functioning as a professional developer introduction.

It features:

- ⚔️ Last World branding
- 🌑 Dark fantasy-inspired design
- ✨ Subtle elemental atmosphere
- 👤 Developer information
- 💻 Web Developer / Game Developer titles
- 🔗 GitHub portfolio link
- 📱 Responsive design

---

## 🎮 About Last World

**Last World** is an original medieval fantasy MMORPG concept centered around a world recovering from a catastrophic event known as **The Collapse**.

Long ago, powerful Relics containing primordial elemental forces were scattered across the world.

Players explore kingdoms, forests, islands, ruins, forgotten civilizations, and dangerous regions while discovering Relics and uncovering the truth behind The Collapse.

The long-term vision is to eventually develop Last World into a large-scale 3D MMORPG.
