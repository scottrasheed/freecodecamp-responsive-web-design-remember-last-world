# 🏴‍☠️ Pirate Adventure

A pirate-themed multimedia project featuring an adventure soundtrack, an animated pirate film, and synchronized English subtitles.

## 🌊 Preview

The project contains:

* 🎵 **Pirate Adventure Music** — an MP3 audio track
* 🎬 **Pirate Adventure Video** — a 1933 animated film featuring Cubby Bear
* 💬 **English Subtitles** — a WebVTT subtitle track synchronized with the video

## 📖 About

**Pirate Adventure** is a simple HTML multimedia project built around an old animated pirate adventure.

The project demonstrates how to embed audio and video into a webpage using HTML5 while also providing subtitles through the `<track>` element.

## 📁 Project Structure

```text
pirate-adventure/
```

## 🛠️ Built With

* HTML5
* `<audio>`
* `<video>`
* WebVTT subtitles
* MP3 audio
* MP4 video

## 🎬 Multimedia Features

### Audio

The project uses the HTML5 `<audio>` element to provide controls for playing the pirate adventure soundtrack.

### Video

The HTML5 `<video>` element displays the animated pirate adventure film with playback controls.

### Subtitles

English subtitles are provided through a WebVTT file using the HTML5 `<track>` element.

## ▶️ How to View

1. Download or clone the project.
2. Make sure the `assets` folder remains in the project directory.
3. Open `index.html` in a web browser.
4. Play the audio or video.
5. Enable **English subtitles** using the video's subtitle/CC controls.

## 📚 What I Learned

This project demonstrates:

* How to add subtitles using WebVTT.
* How to organize multimedia assets into separate folders.
* How relative file paths connect HTML documents to local assets.
