# 😂 Funny Video Compilation

A simple HTML video compilation page created as part of my **freeCodeCamp Responsive Web Design** coursework.

## 📺 Preview

The page features three embedded funny video compilations, each organized into its own section.

## 📝 About

This project was built to practice working with:

* Semantic HTML
* Headings and paragraphs
* `<main>` and `<section>` elements
* Embedded YouTube videos using `<iframe>`
* HTML attributes such as `src`, `title`, `width`, and `height`
* Basic webpage structure

## 📂 Files

```text
funny-video-compilation/
├── index.html
└── README.md
```

### `index.html`

Contains the complete webpage and the three embedded video compilations.

### `README.md`

Provides information about the project and the skills practiced.

## 🎯 freeCodeCamp Requirements

The project was built to satisfy the following requirements:

* A `<main>` element as the only child of `<body>`
* An `<h1>` containing the page topic
* An introductory paragraph
* Three `<section>` elements
* Each section contains an `<h2>`, paragraph, and `<iframe>`
* Each `<iframe>` includes a valid `src`
* Each `<iframe>` includes `title`, `width`, and `height` attributes

## 🛠️ Technologies & Tools

* HTML5
* YouTube `<iframe>` embeds
* Visual Studio Code
* VS Code Live Server

## ▶️ How to Run

### Option 1 — Open Directly

Open `index.html` in your web browser.

### Option 2 — VS Code Live Server

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Right-click inside the file.
4. Select **Open with Live Server**.
5. The project will open in your default browser.

> Live Server is optional. The project is a standalone HTML page and does not require a server to run.
