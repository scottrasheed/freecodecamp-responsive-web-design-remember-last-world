# 🔥 Last World — Emberfest

A custom seasonal event flyer created for **Last World**, an original fantasy MMORPG concept.

This project was built with **HTML5 and CSS3** as part of my **freeCodeCamp Responsive Web Design** journey.

Emberfest is a limited-time seasonal event centered around the **Fire element**, featuring special challenges, exclusive rewards, temporary bonuses, and a limited-time PvP game mode.

> **FIRE AWAKENS. THE WORLD CELEBRATES.**

---

## 🎮 Project Overview

**Last World — Emberfest** is a fictional in-game promotional page designed to showcase a seasonal event within the Last World universe.

The goal was to create something that feels like an official MMORPG event announcement rather than a basic webpage.

The design combines:

- 🔥 Fire-themed visuals
- 🌑 Dark fantasy backgrounds
- 🟠 Ember orange accents
- 🟡 Gold fantasy typography
- ⚔️ Fantasy-inspired UI elements
- 🖼️ Custom event artwork
- ✨ Glowing effects and atmospheric overlays

## 🔥 Emberfest

Emberfest is a seasonal celebration where the power of Fire surges across the Last World.

For a limited time, players can participate in special activities, complete event quests, earn exclusive rewards, and experience increased Relic power.

### Event Duration

**June 20 — July 10**

---

## ⚔️ Event Highlights

### Ember Trials

Face fiery challenges in special dungeons and earn **Ember Tokens**.

Players can complete event-specific challenges while fighting enemies connected to the Fire element.

### Inferno Rush

A limited-time **5v5 PvP game mode** where only the bold survive the blaze.

Players compete against opposing teams in a fast-paced seasonal battle.

### Power Surge

During Emberfest, players receive temporary progression bonuses.

Players receive:

- **+50% EXP**
- **Relic Power Boost**

### Festival of Light

Collect Lanterns, unlock bonuses, and help light up the world together.
