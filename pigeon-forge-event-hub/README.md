# 🎟️ Pigeon Forge Event Hub

A simple event hub webpage featuring upcoming and past events around the **Pigeon Forge and Gatlinburg, Tennessee** area.

## 🌟 Preview

The Event Hub provides a simple way to view upcoming attractions and previously held events, with links to official event websites for more information.

### Upcoming Events

* 🌄 **Gatlinburg SkyPark Adventure** — August 23, 2026
* 🏴‍☠️ **Pirates Voyage Dinner & Show** — September 24, 2026

### Past Events

* 🎵 Mountain Music Festival
* ☀️ Smoky Mountain Summer Celebration

## 🧠 What I Learned

This project helped me practice using **semantic HTML** to structure a webpage.

Some of the elements used include:

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<article>`
* `<h1>`, `<h2>`, and `<h3>`
* `<p>`
* `<a>`
* `<ul>` and `<li>`
* `<img>`

I also practiced:

* Creating navigation links to sections of the same page
* Using `id` attributes for internal navigation
* Linking to external websites
* Adding images with descriptive `alt` text
* Structuring content using semantic HTML elements
